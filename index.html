ADMIN PANEL

Connect this admin to your GitHub repository

This panel updates the same GitHub repository that hosts your ILVORA website. Your access token is kept only in this browser session and is never written into the website files.

The token needs repository Contents: Read and write permission for this repository. Do not paste the token into your website code.

Services

Edit the service cards shown on the public website. Offerings are displayed when visitors open a service.

Careers

Create, edit or remove current job vacancies. Saved vacancies appear in the public Careers section.

Opportunity

Add future projects or partnership opportunities. Only items marked Published appear publicly.

Gallery & Media

Add an image/video by URL or upload a smaller media file into the repository. GitHub Pages is not designed for very large video files; keep uploads modest.

Company Registration Details

These values are displayed in the public Contact section. Enter the official information when available.
